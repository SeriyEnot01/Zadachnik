# Задачник: установка с синхронизацией

Приложение хранит задачи на устройстве и синхронизирует их через вашу бесплатную базу Supabase.
Всё шифруется на устройстве ключом из вашего пароля (PBKDF2 + AES-256-GCM).
В базе лежат только непрочитываемые байты: ни Supabase, ни GitHub, ни владелец проекта не видят текст задач.

## 1. Создать базу (5 минут)
1. Зарегистрируйтесь на https://supabase.com → **New project**. Регион: **Central EU (Frankfurt)**. Пароль базы придумайте любой и сохраните (приложению он не нужен).
2. Откройте **SQL Editor** → **New query**, вставьте содержимое `setup.sql`, нажмите **Run**. Должно быть «Success. No rows returned».
3. **Project Settings → API** (или кнопка **Connect**). Скопируйте:
   - **Project URL**, вида `https://abcd1234.supabase.co`;
   - ключ **anon public** (вкладка *Legacy API keys*) или **publishable**.
   Ключ **service_role / secret** никуда не вставляйте.
4. Вставьте оба значения в `config.js`.

## 2. Выложить на GitHub Pages
1. Создайте репозиторий, например `zadachnik`, и загрузите в него **все файлы из этой папки** (Add file → Upload files).
2. **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save. Через минуту появится адрес `https://ваш-ник.github.io/zadachnik/`.
3. Вернитесь в Supabase: **Authentication → URL Configuration → Site URL**, вставьте этот адрес. Тогда ссылка из письма подтверждения откроет приложение.

## 3. Установить
- **iPhone**: Safari → адрес → «Поделиться» → «На экран „Домой“».
- **Android**: Chrome → меню ⋮ → «Установить приложение».
- **Компьютер**: Chrome / Edge → значок установки в адресной строке.

Создайте аккаунт на одном устройстве, подтвердите почту, затем войдите с той же почтой и паролем на остальных.

## Важно
- **Пароль = ключ шифрования. Его нельзя восстановить.** Сброс пароля через почту не вернёт данные. Храните пароль в менеджере паролей и иногда делайте «Резервная копия → Сохранить в файл».
- Не кладите файлы резервных копий (`zadachnik-*.json`) в репозиторий: на бесплатном тарифе он публичный.
- Бесплатный проект Supabase **засыпает, если неделю им никто не пользуется**. Разбудить: зайти на supabase.com → проект → **Restore**. Задачи на устройствах при этом не пропадают.
- Друзья могут регистрироваться в этом же приложении: у каждого свой аккаунт, свои зашифрованные данные, чужих строк база не отдаст. Лимит бесплатного тарифа: 50 000 активных пользователей в месяц и 500 МБ, этого с запасом.
- Без интернета приложение работает, изменения отправятся при появлении сети.
